# Futebol de Botão

Animação de futebol de botão para a sala de aula: a bola quica pelas bordas e pelos
botões dos dois times, que chutam em direção ao gol adversário de forma aleatória.

- Partida de 1 minuto, mostrada como 90 minutos de jogo (1 segundo = 1,5 minuto).
- Intervalo aos 30 segundos, com troca automática de lado.
- Placar, aviso de gol e tela de fim de jogo com o resultado.
- Velocidade ajustável de 0,25× a 4× (barra, botões ou teclas `+` e `−`).
- A partida só começa ao clicar em "Iniciar partida" (ou tecla Espaço).
- Times personalizáveis: nome, duas cores, estilo da camisa e imagem de escudo,
  que cobre o botão inteiro. As escolhas ficam salvas no navegador.

É uma página única (`index.html`), sem dependências. Para testar, basta abrir o arquivo
no navegador. `escudo-exemplo.png` é uma imagem de exemplo para o campo "Escudo".
